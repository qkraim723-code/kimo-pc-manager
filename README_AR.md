# مدير الكمبيوتر (Kimo PC Manager) 💻✨

**مدير الكمبيوتر (Kimo PC Manager)** هو تطبيق سطح مكتب عربي وإنجليزي متكامل، حديث وسهل الاستخدام، مخصص لنظامي التشغيل Windows 10 و Windows 11 (64 بت). تم تصميمه ليوفر تجربة استخدام ذكية وسلسة مستوحاة من بساطة تطبيقات إدارة الملفات على الهواتف، حيث يجمع كل ما يحتاجه المستخدم من أدوات حقيقية لإدارة الملفات والتخزين ومراقبة الأداء وتنظيف الملفات المؤقتة بأمان تام.

تم بناء التطبيق باستخدام: **بايثون (Python)** و **PySide6 (Qt6)** و **psutil** و **send2trash**.

---

## 🌟 الميزات الرئيسية

### 1. 📊 لوحة التحكم الرئيسية (نظرة عامة)
- واجهة عصرية باللون الأخضر الداكن الهادئ (`#17251F`) والبطاقات الزيتية (`#263830`) مع لمسات الليموني الفاتح (`#C7F36B`).
- مؤشرات مباشرة وحقيقية لاستهلاك المعالج (CPU) والذاكرة العشوائية (RAM) وسعة قرص النظام.
- شريط تقدم تفاعلي يوضح المساحة المستخدمة والمتاحة بدقة حقيقية.
- اختصارات سريعة للوصول إلى الصور، الفيديوهات، المستندات، التنزيلات، الصوتيات، أدوات ويندوز، والملفات المكررة.

### 2. 📁 مدير ملفات متكامل واحترافي
- استعراض كامل لجميع محركات الأقراص الداخلية والخارجية.
- شريط مسار ذكي مع أزرار الرجوع والتقدم والانتقال للمجلد الأب والتحديث.
- تصنيف فوري للملفات: **الصور، الفيديوهات، الصوتيات، المستندات، الملفات المضغوطة، التنزيلات، الملفات الكبيرة (>100 ميجابايت)، والملفات الحديثة**.
- عمليات ملفات آمنة:
  - إنشاء مجلدات جديدة.
  - إعادة تسمية الملفات والمجلدات.
  - نسخ ونقل الملفات مع معالجة ذكية لتعارض الأسماء (إعادة تسمية تلقائية، استبدال، تخطي).
  - حذف الملفات ونقلها إلى سلة المحذوفات باستخدام `send2trash` بدلاً من الحذف النهائي.
  - عرض خصائص الملفات التفصيلية.
  - فتح الملفات بالتطبيقات الافتراضية في ويندوز أو إظهارها في مستكشف ويندوز (Explorer).

### 3. 💾 تحليل مساحة التخزين (Storage Analyzer)
- فحص عميق لأي قرص أو مجلد مخصص في خيوط خلفية غير متزامنة لمنع تجمد البرنامج.
- عرض المجلدات الأكثر استهلاكاً للمساحة مرتبة حسب الحجم ونسبة الاستهلاك.
- قائمة بأكبر الملفات الفردية حجماً.
- معالجة ذكية للأذونات المرفوضة والروابط الرمزية دون انهيار البرنامج.

### 4. 🛡️ مركز التنظيف الآمن (Safe Cleanup)
- **منهجية محافظة وغير تدميرية**: فحص المخلفات المؤقتة فقط (%TEMP%، كاش التصفح الآمن، كاش الصور المصغرة).
- **درع الأمان المطلق**: عدم المساس بملفات ويندوز الأساسية (System32, WinSxS) أو مفاتيح الريجستري أو سجلات النظام المهمة أو ملفات التعريف.
- **تخطي الملفات المقفلة**: تخطي الملفات الجاري استخدامها تلقائياً بدون أخطاء.
- شفافية كاملة: عرض عدد الملفات والمساحة القابلة للتوفير مع نافذة تأكيد قبل الحذف.
- رابط مباشر لفتح سلة محذوفات ويندوز الرسمية.

### 5. ⚡ مراقبة أداء العتاد (Performance)
- مؤشرات حية لاستهلاك المعالج والذاكرة ومعدل القراءة والكتابة للأقراص.
- مواصفات النظام والعتاد (إصدار ويندوز، الأنوية، تاريخ الإقلاع، مدة التشغيل).
- قائمة بالعمليات الأكثر استهلاكاً للموارد مع إمكانية إنهاء العملية بأمان وتحذير مسبق.

### 6. 📑 البحث عن الملفات المكررة (Duplicate Finder)
- خوارزمية دقيقة وسريعة تعتمد على مطابقة الحجم أولاً ثم حساب بصمة SHA-256 للمحتوى.
- تجميع الملفات المكررة وعرض المساحة الممكن استردادها.
- زر «تحديد المكررات تلقائياً» مع قاعدة أمان صارمة: **الاحتفاظ بنسخة أصلية واحدة على الأقل وحمايتها من الحذف**.

### 7. 🔧 أدوات ويندوز الرسمية (Windows Utilities)
- اختصارات سريعة ومباشرة للأدوات المدمجة في ويندوز:
  - إدارة المهام (Task Manager)
  - إعدادات التخزين ومستشعر السعة (Storage Sense)
  - معلومات النظام (msinfo32)
  - تحسين وإلغاء تجزئة الأقراص (dfrgui)
  - أداة تنظيف القرص الكلاسيكية (cleanmgr)
  - إدارة الأجهزة (Device Manager)
  - مراقب الموارد المتقدم (Resource Monitor)
  - لوحة التحكم (Control Panel)

### 8. 🌐 ثنائي اللغة بالكامل (العربية والإنجليزية)
- **اللغة العربية (الافتراضية)**: واجهة كاملة من اليمين إلى اليسار (RTL) بخطوط وتنسيقات واضحة.
- **اللغة الإنجليزية**: واجهة كاملة من اليسار إلى اليمين (LTR).
- إمكانية التبديل الفوري بين اللغتين من صفحة الإعدادات مع حفظ تفضيلات المستخدم.

## 🔒 قواعد الأمان والخصوصية

- يعمل بصلاحيات المستخدم العادي ولا يطلب صلاحيات مسؤول النظام (Administrator).
- لا يرسل أي بيانات أو أسماء ملفات عبر الإنترنت (بدون أي خوادم تتبع أو إعلانات).
- حذف الملفات يتم عبر سلة محذوفات ويندوز افتراضياً.
- كود مفتوح المصدر قابل للتدقيق والفحص بالكامل.

## 🚀 طريقة التشغيل لأول مرة

### المتطلبات
تأكد من وجود بايثون 3.11 أو أحدث على جهازك:
```bash
python --version
```

### التثبيت والتشغيل
1. افتح مجلد المشروع في موجه الأوامر (CMD أو PowerShell).
2. ثبّت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
3. شغّل التطبيق:
   ```bash
   python main.py
   ```
   أو اضغط نقراً مزدوجاً على الملف: `run.bat`.

## 📦 بناء نسخة تنفيذية (EXE)

لبناء نسخة جاهزة للتشغيل دون الحاجة لتثبيت بايثون:
اضغط نقراً مزدوجاً على `build.bat` أو نفّذ الأمر التالي:
```bash
pyinstaller --noconfirm --onedir --windowed --name "KimoPCManager" --icon "assets/icon.ico" --add-data "locales;locales" --add-data "assets;assets" main.py
```
ستجد الملف التنفيذي الناتج داخل المجلد:
```
dist\KimoPCManager\KimoPCManager.exe
```
