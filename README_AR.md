# مدير الكمبيوتر Kimo PC Manager

تطبيق سطح مكتب لنظام Windows يساعدك على إدارة الملفات، وفهم استهلاك مساحة الأقراص، ومراجعة الملفات المؤقتة، ومتابعة نشاط الجهاز من واجهة واحدة.

[English](README.md) | [العربية](README_AR.md)

## ماذا يقدم التطبيق؟

- **مدير الملفات:** استعراض الأقراص والمجلدات، وإنشاء العناصر وإعادة تسميتها ونسخها ونقلها، وإرسال الملفات المحذوفة إلى سلة محذوفات ويندوز.
- **تحليل التخزين:** فحص قرص أو مجلد تختاره وعرض أكبر المجلدات والملفات.
- **التنظيف الآمن:** مراجعة فئات الملفات المؤقتة المدعومة وأحجامها قبل أن تختار حذفها.
- **البحث عن المكررات:** العثور على الملفات المتطابقة بمقارنة الحجم وبصمة SHA-256، مع حماية نسخة واحدة على الأقل في كل مجموعة.
- **مراقبة الأداء:** عرض استهلاك المعالج والذاكرة ونشاط القرص والعمليات الجارية. إنهاء عملية قد يؤدي إلى فقدان العمل غير المحفوظ في ذلك البرنامج.
- **أدوات ويندوز:** فتح مجموعة من الأدوات المضمنة في Windows.
- **الدعم والإعدادات:** نسخ بيانات الدعم، وفتح مجموعة تيليجرام، والتحكم في إعلان بدء التشغيل الاختياري.

## اللغات

واجهة التطبيق متاحة **بالإنجليزية والعربية**. الإنجليزية هي اللغة الافتراضية، والعربية تستخدم تخطيطاً من اليمين إلى اليسار. يمكنك تغيير اللغة من الإعدادات.

## تنزيل التطبيق

افتح صفحة **Releases** في المستودع ونزّل أحدث حزمة Windows x64 عند نشر إصدار. فك ضغط الحزمة كاملة ثم شغّل `KimoPCManager.exe`. الحزمة تتكون من مجلد وملفات مساعدة؛ لا تنقل الملف التنفيذي وحده خارج مجلده. قد يطلب Windows موافقة المسؤول عند تشغيل النسخة المعبأة.

إذا لم يتوفر إصدار للتنزيل بعد، يمكنك بناء التطبيق من السورس باتباع الخطوات التالية.

## التشغيل من السورس

المتطلبات: Windows 10 أو 11 (64 بت) وPython 3.11 أو أحدث.

```powershell
git clone https://github.com/<owner>/<repository>.git
cd <repository>
python -m pip install -r requirements.txt
python main.py
```

استبدل `<owner>` باسم حساب GitHub و`<repository>` باسم المستودع. ويمكنك أيضاً تشغيل `run.bat` من مجلد المشروع.

## بناء نسخة Windows

من مجلد المشروع شغّل:

```powershell
build.bat
```

يستخدم البناء PyInstaller ويضع التطبيق في `dist/KimoPCManager-Verified/KimoPCManager/KimoPCManager.exe`. عند مشاركة التطبيق احتفظ بمجلد `KimoPCManager` كاملاً. ينشئ البناء أيضاً اختصاراً داخل مجلد المشروع وعلى سطح مكتب Windows.

## الخصوصية والأمان

- لا يحتوي التطبيق على أدوات تحليلات أو تتبع للاستخدام.
- يعرض التطبيق عمليات التنظيف والحذف قبل تنفيذها؛ وحذف الملفات العادي يستخدم سلة محذوفات ويندوز متى كان ذلك مدعوماً.
- إعلان بدء التشغيل الاختياري مفعّل افتراضياً. عند تفعيله، يفتح التطبيق رابط الإعلان المحدد في متصفحك الافتراضي عند بدء التشغيل. يمكنك إيقافه من **الإعدادات ← الدعم والإعلانات**. عند فتح الرابط يتصل المتصفح بالموقع الخارجي وفق سياسة الخصوصية الخاصة به.
- تطلب النسخة التنفيذية المعبأة موافقة المسؤول عبر Windows. أما تشغيل `python main.py` فلا يرفع صلاحيات Python تلقائياً.

## السورس والمساهمات

الكود مكتوب ببايثون ومقسّم إلى `core/` لخدمات الملفات والنظام، و`ui/` للواجهة، و`locales/` للنصوص العربية والإنجليزية، و`tests/` للفحوصات الآلية. يمكنك الإبلاغ عن مشكلة أو اقتراح تحسين عبر GitHub Issues وPull Requests.
